# NovaTech Returns Policy

Version 1.3 — effective 1 January 2024.

## Return window

Products can be returned within **14 days of purchase**.

## Conditions

- Items must be unopened and in their original packaging.
- Opened items are accepted only if defective.
- A **15% restocking fee** applies to all non-defective returns.

## Exclusions

- All headphones and earbuds once opened.
- Software, gift cards, and clearance items.

## Process

Bring the item with the invoice to the store where you bought it. Online orders must be returned to the Amman store.
